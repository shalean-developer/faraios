# T05 — Hosting evidence required

Status: not verified. Budget target R500/month is not a measured cost.

Keep existing websites and hosting subscriptions operational. The presence of faraios.com in Plesk does not prove application capability or available capacity.

Record these from the FaraiOS subscription or provider before provisioning:

| Evidence | Needed to decide |
|---|---|
| Node.js versions and application startup support | Supported web framework/runtime |
| RAM, CPU, storage and process limits | Build location and application capacity |
| SSH or deployment capabilities; Git support | Controlled GitHub deployment method |
| Subdomain, TLS and environment-variable support | Staging/production separation |
| Scheduled task support and outbound networking | Background jobs and provider integration |
| Existing plan cost and incremental charges | Hosting budget |
| Database/auth/storage cost and quotas | Isolated staging and production architecture |
| Backup/restore, logs and monitoring access | Reliability and recovery |
| Email/message service costs and quotas | Communication budget and limits |

Do not commit a hosting provider, new subscription or deployment based on assumptions. Owner can supply the Plesk Node.js and resource/limits screens, or grant read-only browser access to inspect them. Never request credentials in chat.

Exit: actual capabilities documented, compatible application stack chosen, ongoing costs/usage limits reviewed, and environment/recovery plan accepted.

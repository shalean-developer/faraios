## Implementation

Welcome → Quotes; enquiry detail → Create quote with private customer/requirements prefill. Manual drafts support customer name, email and/or phone, up to 20 items, integer quantities 1–9999, nonnegative exact minor-unit prices, final offered total, notes and expiry. Catalogue service names/prices are suggestions; owner enters the agreed price explicitly. No tax calculation or PDF/email issuance. Quote currency is captured from the business catalogue (ZAR default); whole-unit currencies enforced. Maximum total 9,999,999.99. Expiry is inclusive through the selected date in the business time zone; draft save permits today through 366 days ahead. Draft totals shown after save. Mark sent uses the last saved quote and explicit confirmation; edits must first be saved.

Sending freezes document, expiry, business display name and explicit public contacts/time zone, then creates a cryptographically random 256-bit bearer link. Sender account details never enter the shared payload. The customer sees their name/items/notes and sender public contacts, with no other customer's record or enquiry/owner/business IDs. Drafts have no token. Anyone holding a link can view that single sent quote and give its one final accept/decline response before expiry. Treat the link as confidential; this first release has no token revocation or replacement. Sent quotes cannot be edited; create another quote for revisions. No booking or payment results from a response. Owner statuses: Draft, Sent, Accepted, Declined, Expired. Expired is calculated at read time, without a scheduled worker; final responses retain their final status.

Tables have RLS and authenticated SELECT only, using existing business owner policies. No anonymous table/view access or direct owner writes. Narrow private definer functions enforce exact owner UID/nonanonymous claims before every write, matching business/environment/enquiry, bounded validation, immutable sent data, expected version and serialized row changes. Anonymous access is only the bounded capability RPC; fixed empty search paths, explicit grants and return allowlist. Private schema is not intended to be exposed by Data API. Owner list view uses security_invoker=true and filters/paginates effective status in SQL. Form CSRF/origin checks, isolated customer cookies, escaped text, no-store/noindex headers and frame denial apply. The URL token can appear in browser history and hosting logs; no analytics/third-party assets added. Random token guessing is infeasible; no CAPTCHA or dedicated high-volume abuse test claimed.

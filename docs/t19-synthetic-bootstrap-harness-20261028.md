It starts no container. `--run EXPECTED_JSON PRIVATE_NEW_DIRECTORY APPROVAL_JSON` requires an Ed25519 owner signature under the independently provisioned root-owned Gate2 trust key. This is a distinct synthetic-bootstrap scope; historical Gate2 approvals cannot authorize it. The receipt binds the source bundle, pinned Docker, fresh full baseline, expected catalogue bytes, boot/daemon identity and private journal directory, and expires after15 minutes. A durable consumed-nonce record prevents replay in that bound directory.

The host must be Linux/root with the accepted Node24.22.1 and Docker bytes, the original13 exited containers, at least3 GiB available memory and2 GiB available disk, and all three cached pinned images. PostgreSQL's derivative must inherit all29 original layers and exact image configuration, adding one layer. Missing resources or changed baseline fail before mutation. All source/input paths must be root-owned without symlink or group/world-write components; private expectation and journal must exclude group/world access.

The orchestrator advances through isolation → vendor PostgreSQL initialization → Auth migrations → Auth index worker → Storage through0073 → full managed catalogue → inactive custody overlay → permitted/denied synthetic API/SQL → stable catalogue/empty state → cleanup. Failure stops progression. An unknown Docker outcome or signal fences mutations and returns quarantine. No automatic retry of a mutation or force/prune fallback exists.

Each container is nonce-bound, nonroot, read-only, capability-free, no-new-privileges, with one CPU,512 MiB memory/no extra swap,64PIDs, bounded tmpfs and bounded local logs. No host ports, binds, devices, host namespaces, existing volumes or Docker socket. At most four containers are retained concurrently; PostgreSQL/Auth/Storage run on a fresh internal bridge. A separately owned internal sentinel bridge proves same-network reachability and cross-network denial using a synthetic HTTP sentinel. These probes are not internet scans and never contact a real service.

Money is stored in integer hundredths for **all current currencies**. JPY/UGX/RWF require amounts divisible by 100; do not reinterpret stored integers as ISO minor units. No tax/FX/legal readiness is inferred from currency choices. SC-02 pilot currency stays ZAR.

Frozen synthetic examples cover eight-field profile, optional area profile, no-options catalogue, all five option kinds, included/zero selections, fixed/from/quote/free and whole-JPY arithmetic, six/seven-field documents, scoped request/booking, quote token/sender, invoice predecessor/active successor, payment/reversal, counter and inactive assignment. They are **selected field projections**, not complete database rows or a data import. New native tests validate JSON and create financial records through existing RPCs; native request→scope→booking→invoice parity remains covered by existing `rooms.py` regression. Arbitrary homepage/SEO/presentation generations are documented and source-fingerprinted, not claimed as populated fixture coverage for every optional field.

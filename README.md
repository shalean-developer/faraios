# FaraiOS

Fresh, approved Home page for faraios.com. A self-contained static website with no build step or dependencies.

## Deployment

In Plesk, connect this repository using HTTPS, select `main`, and deploy the repository root to the domain document root `/faraios.com`. No build command is needed. Pull and deploy subsequent approved commits from Plesk.

## Scope

Home page only. Product mockups are labelled concepts. The waitlist action displays a coming-soon notice; it does not collect personal information. No dashboard, authentication, database, booking or payment functionality is included.

Brand source files: `FaraiOS-logo.svg` and `favicon.svg`. The homepage embeds these assets for reliable loading.
